# image —— 素材暂存目录

这个目录用来放**待替换 / 待上线的原始素材**：照片、视频、宣传图等。
素材定稿后，再按下面的对应关系接到页面上。

## 目录用途

| 目录 | 放什么 | 会用在哪里 |
| --- | --- | --- |
| `logo/` | 工作室正式 logo，建议再留一份透明底 PNG | `index.html` 顶部与页头，以及 `assets/img/logo.svg` 的替换 |
| `members/` | 成员照片，1:1 正方形，边长 600px 以上 | `members.html` 里各成员卡片的照片位 |
| `works/` | 作品封面图、截图 | `works.html`（内容待补） |
| `video/` | 宣传片、作品演示视频（mp4 / webm） | 首页或作品页的视频位（需要时再接） |

## 命名建议

- 全用英文小写 + 连字符，避免空格和中文，防止链接里出现转义问题。
- 成员照片用姓名拼音：`jiang-yunting.jpg`、`zhou-pengcheng.jpg`。
- 作品图带序号或作品名：`work-01-cover.jpg`、`work-02-shot-1.png`。
- 视频同理：`studio-promo.mp4`，封面图另存一张同名 `.jpg`。

## 关于体积

- 图片先用 JPG/PNG/WebP，单张尽量压在 500KB 以内；放进来前压缩一下，网页加载会快很多。
- 视频建议单条不超过 50MB，格式优先 mp4（H.264）；更大的源文件放这里当备份可以，但别直接挂到网页上。

## 注意

页面目前引用的是 `assets/img/` 下的文件（占位 logo、成员占位头像）。
素材放进本目录后告诉我一声，我负责改名、压缩并替换到对应页面里。
